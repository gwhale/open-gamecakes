## What this means in practice

- **Run it for your own family** with the name and mascot intact — that's the
  point of the project.
- **Fork it, change it, redistribute it** freely under the MIT license — but a
  publicly hosted fork that diverges from this codebase should use its own
  name and mascot so families can tell what they're using.
- **Subdomains of gamecakes.org** are granted case-by-case to good-faith
  deployments of this codebase. Open an issue to ask.

This is the same arrangement most open-source products use (the code is free;
the identity is not) and it exists for one reason: parents should be able to
trust that something calling itself Gamecakes is the real thing.
